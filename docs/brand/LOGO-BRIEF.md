# Wharf 码头 · Logo 设计简报

## 项目是什么

**Wharf（码头）** 是一个开源的 OpenWrt / iStoreOS 路由器控制面板，以 LuCI 插件形式安装在家用或小型办公路由器上，用浏览器或手机打开。

它解决的问题：OpenWrt 功能强，但只有懂命令行的人能用。Wharf 让一家人、几位管理员一起看懂并管好网络：
- **看得懂**：每台设备是谁、在访问什么（视频、AI、游戏……）、流量飞向哪些国家（全球飞线地图）。
- **管得住**：端口转发按地区限制来源，端口段可以分给不同的管理员；可以一键断网、定时断网、设置黑白名单。
- **查得清**：路由追踪地图、抓包自动分析、定时监控、局域网扫描，排障结论能直接交给运营商。
- **靠得住**：多管理员权限隔离，所有修改都有审计、可一键还原；只用 OpenWrt 原生机制，不改内核、不断网。

目标用户：玩路由器的技术爱好者、家里的「网管」、小团队；也包括他们的家人（面板有「简要模式」）。

## 名字的含义（logo 的灵感来源）

- **Wharf = 码头**：船（数据包）在这里停靠、装卸、再出发。路由器就是家庭网络的码头，所有进出流量都经过它。
- **Port 双关**：英文 port 既是「港口」也是「端口」。端口转发、端口段授权正是 Wharf 的招牌功能。
- 可以借用的意象：码头栈桥 / 系船柱（bollard）/ 锚 / 灯塔 / 集装箱 / 船只进出港 / 航线。这些都可以和「网络流量、连接、路由」结合，例如栈桥的木板像数据通道，航线像路由路径。
- 气质：**可靠、清晰、友好、有秩序**。不要做成「黑客风」，也不要太卡通。

## 现状（可以完全推翻）

- 现在的图标是临时的：蓝色渐变圆角方块，中间一个白色线条「路由器」图形（lucide 的 router 图标）。
- 主色：蓝色渐变 `#3b8bf6 → #1d5fe0`；界面主色约 `oklch(0.58 0.21 258)`（≈ `#2563eb`）。
- PWA 背景色 `#0b1220`（深海军蓝），主题色 `#1d5fe0`。
- 界面风格：类似 UniFi 的扁平、干净、留白多、圆角卡片；支持浅色和深色模式；字体 Geist（英文）+ 系统中文字体。
- 全球流量大屏是深蓝色地图配青色飞线（`#22d3ee`、`#38bdf8`）、黄色「家」的标记（`#facc15`）。如果 logo 想呼应，可以考虑这组颜色。

## 需要的成品

1. **图形标（mark）**：单独的符号，必须在 **16×16 favicon** 下仍然认得出（这是硬性要求，所以线条不能太细、细节不能太多）。
2. **文字标（wordmark）**：
   - 英文 `Wharf`
   - 中英组合 `Wharf 码头`
   - 横版：图形 + 文字
3. **配色版本**：
   - 彩色
   - 纯白（用在深色背景上）
   - 纯黑 / 单色（用在浅色背景上）
   - 深色模式适配
4. **应用图标**：圆角方块底板版本，用于 PWA、手机主屏幕和 LuCI 菜单。其中 maskable 版本要保证主体在中心 80% 的安全区内。

## 用在哪里 / 需要的尺寸

| 用途 | 尺寸 / 格式 |
|---|---|
| 浏览器标签 favicon | SVG + 16 / 32 px |
| 面板侧栏、登录页 | 32–44 px（SVG） |
| PWA 图标 | 192、512 px PNG；512 maskable |
| iPhone 主屏幕 | 180 px PNG（apple-touch-icon） |
| GitHub 仓库头像 | 512 px 方形 |
| GitHub 社交分享图 | 1280 × 640（logo + 一句标语 + 面板截图氛围） |
| README 顶部横幅 | 横版 wordmark，浅色 / 深色两版 SVG |

**交付**：Figma 源文件 + 导出的 SVG（干净的 path，不嵌位图，颜色尽量少）+ 上表中的 PNG。

## 可选标语（供社交分享图使用）

- 「让 OpenWrt 一家人都看得懂」
- "Your router's harbour — see, share and secure your home network."
- "A multi-admin control panel for OpenWrt."

## 避免

- 和 OpenWrt 官方 logo、iStoreOS logo 或 UniFi logo 太像。
- 直接用 Wi-Fi 信号扇形、路由器天线这类千篇一律的符号作为主体。
- 渐变太复杂，或依赖阴影 / 3D 效果（会影响小尺寸和单色版）。
