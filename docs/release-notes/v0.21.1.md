Panels on 0.17 – 0.21 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 – 0.21 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：


### A new subdomain that won't open at home · 新建的域名在家里打不开
- A name looked up before its record existed is remembered as "does not exist" for the zone's negative TTL — 30 minutes on Cloudflare — by every cache on the way. *DHCP 与 DNS → DNS 缓存与排查* asks dnsmasq, NextDNS on the router, the NextDNS cloud, 1.1.1.1 and the domain's authoritative servers, and names the layer that is behind; it also recognises rebind protection dropping a private address (allow it in one click), a NextDNS block, or a record that really doesn't exist.
  查询过「还不存在」的域名，会被沿路的缓存按域名的设置记住（Cloudflare 是 30 分钟）。「DHCP 与 DNS → DNS 缓存与排查」逐层询问 dnsmasq、路由器上的 NextDNS、NextDNS 云端、1.1.1.1 和域名的权威服务器，指出卡在哪一层；也能认出被防 DNS 重绑定丢掉的内网地址（一键放行）、被 NextDNS 拦截、或记录本身不存在。
- *刷新 DNS 缓存* empties dnsmasq's cache without interruption and restarts NextDNS (about a second).
  「刷新 DNS 缓存」清空 dnsmasq 缓存（不中断），并重启 NextDNS（约 1 秒）。
- *NextDNS 缓存最长保留* caps how long NextDNS keeps any answer, so new records show up at home within minutes without refreshing by hand.
  「NextDNS 缓存最长保留」限制 NextDNS 保留任何结果的时间，新建的记录几分钟内自动生效。
