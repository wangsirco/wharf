**Wharf 码头 0.20.0 — Interfaces, DHCP / DNS, firewall and plugins · 网络接口、DHCP / DNS、防火墙与插件**

The router's own settings are now in Wharf, so there is no need to open LuCI for everyday things.
路由器本身的设置搬进了 Wharf，日常不用再打开 LuCI。

### Install / upgrade · 安装与升级
Panels on 0.17 – 0.19 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 – 0.19 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.20.0-1_<arch>.ipk
```

### Network interfaces · 网络接口
- Online or not, how long the line has been up, and the **public IP** — with whether the router holds it directly, sits behind a modem, or is behind carrier-grade NAT.
  是否联网、宽带连续在线多久，以及**公网 IP**——并说明是路由器直接拿到的、在光猫后面，还是运营商大内网。
- A card per interface (LAN, WAN, WAN6, any WAN2): addresses, gateway, DNS, cable and link speed, traffic, firewall zone, multi-WAN state. Restart, stop, edit (DHCP, static, PPPoE, DHCPv6 …), add or delete.
  每个接口一张卡片：地址、网关、DNS、网线与速率、流量、防火墙区域、多线状态；可以重启、停止、修改（DHCP、静态、PPPoE、DHCPv6…）、新增或删除。
- **Changes can't lock you out:** interface and firewall changes take effect at once, and are kept only when you confirm within 90 seconds. Otherwise — or if the router restarts meanwhile — it puts the old settings back.
  **改错了也不会把自己关在外面**：接口和防火墙改动立即生效，90 秒内确认才保留；不确认（或期间路由器重启）就自动恢复原来的设置。

### When the internet is down · 断网时
- Every page shows a red *外网断了* bar. *诊断网络* checks cable → address → ISP gateway → internet → DNS → web and tells you whether it's your side, the account, the ISP, or DNS / a proxy plugin.
  每个页面顶部出现红色「外网断了」；「诊断网络」逐段检查，告诉你是家里、账号、运营商还是 DNS / 代理插件的问题。

### DHCP / DNS and firewall · DHCP / DNS 与防火墙
- Address pools, upstream DNS (recognises NextDNS, SmartDNS, OpenClash …), static leases with clash checks.
  地址池、上游 DNS（认得出 NextDNS、SmartDNS、OpenClash 等插件）、带冲突检查的固定 IP。
- Firewall defaults, zones, zone forwarding and traffic rules; leftover interfaces in zones can be cleaned up.
  防火墙默认策略、区域、区域转发和通信规则；区域里残留的接口可以一键清理。

### Plugins · 插件
- Every installed LuCI app with its state, processes and ports; open a port to the WAN in one click; warnings when two proxy or DNS plugins run at once.
  每个已装插件的状态、进程、端口；一键向外网开放端口；两个代理或 DNS 插件同时运行会提醒。
- **Each plugin's settings pages redrawn in Wharf's design** and editable — OpenClash, PassWall, mwan3, NextDNS, SmartDNS and most others. Parts a plugin draws itself link to LuCI.
  **插件的设置页换成 Wharf 的样式**并可以直接修改——OpenClash、PassWall、mwan3、NextDNS、SmartDNS 等大多数插件都可以。插件自己画的部分给出 LuCI 链接。
- **Plugin store** on the router's own software feeds, with a compatibility check (dependencies, architecture, space, clashes) before installing.
  **插件商店**：来自路由器自己的软件源，安装前检查依赖、架构、空间和冲突。

New permissions can be granted separately: view network settings, change interfaces / DHCP, change the firewall, view / manage / install plugins.
新增权限可以单独授予：查看网络设置、修改接口与 DHCP、修改防火墙、查看 / 管理 / 安装插件。
