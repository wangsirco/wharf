**Wharf 码头 0.18.2 — passkeys and device recognition · Passkey 登录与设备识别**

### Install / upgrade · 安装与升级
Panels on 0.17 / 0.18 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 / 0.18 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.18.2-1_<arch>.ipk
```

### Passkey sign-in · Passkey 登录
- Sign in with Face ID, a fingerprint or a security key; the password keeps working. Add passkeys under *账号安全* in the top-right menu, one per device or password manager.
  用 Face ID、指纹或安全密钥登录，密码依然可用。在右上角「账号安全」里添加，每台设备 / 每个密码管理器一个。
- Browsers only allow passkeys on a domain name with a trusted certificate, so the panel now has names: **wharf.lan** (answered by the router, covered by the panel certificate; install the certificate once per device), and optionally **your own domain** with a Let's Encrypt certificate obtained through a Cloudflare DNS challenge — nothing to install, no port to open.
  Passkey 只能在域名上、证书受信任时使用：本地域名 **wharf.lan**（路由器解析，面板证书覆盖，设备装一次证书），或可选的**你自己的域名**（通过 Cloudflare DNS 验证自动申请 Let's Encrypt 证书，不用装证书、不用开端口）。
- Same rate limit, access control and audit as password sign-in.
  与密码登录相同的限速、访问控制和审计。

### Device recognition · 设备识别
- Phones with private (randomised) MACs and devices without a hostname are now recognised from what they reveal: the **DHCP fingerprint** (the options a device asks for; iPhone, Android with its version, Windows and Mac all differ), **mDNS** (Apple devices give their name and model; an Apple TV / HomePod answers for sleeping iPhones; TVs, printers and HomeKit devices describe their services) and **UPnP** (TVs, consoles, NAS).
  隐私 MAC 的手机和没有主机名的设备，现在按它们透露的信息识别：**DHCP 指纹**、**mDNS**（苹果设备报出名称和型号，Apple TV / HomePod 代答睡眠的 iPhone）、**UPnP**（电视、游戏机、NAS）。
- Names such as "iPhone / iPad（隐私 MAC）", "三星 手机（隐私 MAC）", "Google TV Streamer"; the device page says which signal was used. Both collectors can be turned off under *Settings → 设备识别*.
  名称会显示为「iPhone / iPad（隐私 MAC）」「三星 手机（隐私 MAC）」「Google TV Streamer」等，设备页会写明识别依据；两项都可在设置里关闭。

### Alerts · 告警
- Every message ends with its time and time zone (new *时区* setting, the router's by default). Device left / came back messages give the leave and return times, how long the device was home or away, its model, system, IP and MAC. Telegram titles are bold.
  每条消息写明时间与时区（新增「时区」设置，默认跟随路由器）；设备离开 / 回来写明离开和回来时间、在家或离开多久、型号、系统、IP 和 MAC；Telegram 标题加粗。
- **Fix:** adding a Telegram channel always failed with "格式不正确". The Chat ID can now be left empty — the panel finds it from the bot's messages — and the bot token can be pasted in any form.
  **修复**：添加 Telegram 渠道总是提示「格式不正确」。现在 Chat ID 可以留空自动获取，Bot Token 怎么粘贴都行。
