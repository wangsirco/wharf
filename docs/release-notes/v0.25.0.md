**Wharf 码头 0.25.0 — One name at home, Berth v3 · 内网名字不带端口、Berth 互联 v3**

### Install / upgrade · 安装与升级
Panels on 0.17 – 0.24 show this update in the top bar (*Settings → Updates & maintenance*). New installs:
0.17 – 0.24 的面板会在顶栏提示更新（「系统设置 → 更新与维护」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.25.0-1_<arch>.ipk
```

### One name, no port · 一个名字，不带端口
- Open the panel at https://wharf.lan: turn on *Without a port* in *Settings → Remote access & links → Access addresses*. LuCI is unaffected (opening the router by IP still shows LuCI).
  在「系统设置 → 外网与联动 → 访问地址」打开「不带端口」，就能用 https://wharf.lan 打开；路由器自己的 LuCI 不受影响。
- The card checks whether this device can open the name and shows how to trust the certificate; opened by IP, the panel moves to the name by itself when it can.
  卡片会检查这台设备能不能打开，并给出信任证书的步骤；用 IP 打开时能打开名字就自动转过去。

### Berth v3 · Berth 互联 v3
- Choose LAN or public linking when pairing, switch later without pairing again; *Open Berth* picks the name you can reach (asks when unsure).
  配对时选内网互联或公网互联，以后可切换；「打开 Berth」自动判断在家还是在外，拿不准就让你选。
- Berth's overview can show Wharf's devices, traffic, visitors and DNS figures (new read-only scope).
  Berth 的总览可以显示 Wharf 的设备、流量、访客和 DNS 统计（新的只读权限）。

### Remote access · 外网访问
- Four ways with a recommendation from your line; the Cloudflare tunnel is set up and stopped right in the card, in one step each.
  四种方式按线路推荐；Cloudflare 隧道在卡片里一键开放、一键停止。
- Passkeys follow names: the panel tells you where your passkey is and helps you add one on the new name.
  Passkey 跟着名字走：会告诉你 Passkey 在哪个地址，并帮你在新地址上加一个。

### Fixes · 修复
- A connection leak behind the new LAN 443 sharing could make the panel's names stop working; fixed, with limits and timeouts everywhere.
  修复 443 分流背后的连接泄漏（会导致面板名字全部打不开），并给所有服务加上上限和超时。
