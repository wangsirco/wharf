**Wharf 码头 0.17.0 — first public release · 首个公开版本**

A multi-admin control panel for OpenWrt / iStoreOS: see, share and secure your home network.
给全家人和多位管理员一起用的 OpenWrt 控制面板：看得懂、管得住、查得清。

### Install · 安装
Download the ipk for your router's architecture below, then:
下载对应架构的 ipk，然后：
```sh
opkg install /tmp/luci-app-wharf_0.17.0-1_<arch>.ipk
```
Open LuCI → Services → Wharf 码头 for the panel address and the admin password.
打开 LuCI「服务 → Wharf 码头」查看面板地址和管理员密码。

| Architecture · 架构 | File · 文件 |
|---|---|
| x86_64 (PC, VM, soft router · 软路由 / 虚拟机) | `luci-app-wharf_0.17.0-1_x86_64.ipk` |
| aarch64 (most ARM64 routers · 大部分 ARM64 路由器) | `luci-app-wharf_0.17.0-1_aarch64_generic.ipk` |
| arm cortex-a7 | `luci-app-wharf_0.17.0-1_arm_cortex-a7_neon-vfpv4.ipk` |
| mips / mipsel 24kc | `…_mips_24kc.ipk` / `…_mipsel_24kc.ipk` |

`wharf-web-*.tar.gz`, `wharf-manifest.json` and its `.sig` are used by the panel's signed online update; you don't need to download them.
`wharf-web-*.tar.gz`、`wharf-manifest.json` 及签名文件供面板在线更新使用，无需手动下载。

### Highlights · 亮点
- Signed, per-component online updates · 签名的按组件在线更新
- Port-forward usage analytics with scan / brute-force detection · 端口转发用量与扫描 / 爆破识别
- Packet capture with automatic diagnosis, scheduled monitors, LAN scan, route trace map · 抓包自动诊断、定时监控、局域网扫描、路由追踪地图
- Multi-admin permissions, approvals and full audit with restore · 多管理员权限、审批、审计与还原
- Optional components installed from the panel and removed on uninstall · 依赖组件一键安装、随面板卸载

Full manual · 完整手册: [docs/MANUAL.md](https://github.com/wangsirco/wharf/blob/main/docs/MANUAL.md)

> Tested on iStoreOS 22.03 x86_64. Other architectures are built from the same code but not yet tested on real hardware — reports welcome.
> 已在 iStoreOS 22.03 x86_64 上实际使用；其他架构由同一份代码构建，尚未在真机上测试，欢迎反馈。
