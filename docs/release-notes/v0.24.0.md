**Wharf 码头 0.24.0 — Berth pairing v2, verdict line, settings tabs, phones · Berth 互联 v2、一句话结论、设置分类、手机**

### Install / upgrade · 安装与升级
Panels on 0.17 – 0.23 show this update in the top bar (*Settings → Updates & maintenance*). New installs:
0.17 – 0.23 的面板会在顶栏提示更新（「系统设置 → 更新与维护」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.24.0-1_<arch>.ipk
```

### Berth pairing v2 · Berth 互联 v2
- LAN discovery: allow requests for 10 minutes, Berth asks, compare the six-digit code, allow — Berth finishes pairing by itself.
  内网发现：打开 10 分钟申请窗口，Berth 申请后核对六位校验码，点「允许」即可，Berth 自动完成配对。
- The pairing page explains both addresses: LAN with Wharf's fingerprint, public names with their public certificate (no fingerprint to compare).
  配对页说清两种地址：内网地址核对本地指纹，公网域名按域名校验、不用核对指纹。
- Several Berth addresses, LAN first, switched automatically; link status (LAN / Tailscale / public via Cloudflare …), latency and jitter.
  Berth 多个地址内网优先、自动切换；显示互联方式、延迟和抖动。
- Signed requests stop carrying the token once Berth supports it; Berth may register `.lan` names in the router's DNS.
  双方支持后签名不再带令牌本身；Berth 可以在路由器 DNS 里登记 `.lan` 名字。

### Easier to use · 更好上手
- The overview starts with "一切正常" or the most pressing problem and where to fix it.
  概览最上面一句话：一切正常，或者最要紧的问题和去哪处理。
- Settings in four tabs; search (⌘K) finds settings such as Passkey, attack mode or DNS cache.
  系统设置分四个标签；⌘K 能直接搜到 Passkey、受攻击模式、DNS 缓存等设置项。
- Errors in plain words with what to do; a busy router is retried automatically.
  出错时说人话、给下一步；路由器忙着重启服务时自动重试。
- On phones, tables become cards and a bottom bar holds the common actions.
  手机上表格变卡片，底部有常用操作栏。
