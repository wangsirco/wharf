**Wharf 码头 0.22.0 — Cloudflare, Berth, page contents, proxy usage · Cloudflare、Berth、页内目录、代理用量**

### Install / upgrade · 安装与升级
Panels on 0.17 – 0.21 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 – 0.21 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.22.0-1_<arch>.ipk
```

### Cloudflare gets its own menu · Cloudflare 独立菜单
- **Tunnel:** open the panel from outside without a public IP or an open port. cloudflared is downloaded from Cloudflare's own releases (checksum checked) to the data disk and runs as nobody; adding a name creates the tunnel, its route and the DNS record. Home web services can be published too.
  **隧道：** 没有公网 IP、不开端口也能从外面打开面板。cloudflared 从 Cloudflare 官方下载（核对校验值）到数据盘、以 nobody 运行；添加名字时自动建隧道、路由和解析记录，也能公开家里的其他网页服务。
- **Domains:** attack mode, cache purge, a week of edge statistics. **Access:** an email code before anyone sees the login page.
  **域名与防攻击：** 受攻击模式、清缓存、7 天边缘统计。**Access：** 先过邮箱验证码，陌生人连登录页都看不到。
- The token is set up in two steps with every permission explained and checked. Objects of other tools in the same account (Berth's tunnel, its Access apps) are shown read-only.
  令牌两步设好，每项权限都有说明和检查；同一账户里别的工具（如 Berth）建的东西只读显示。

### Berth · 泊位
- A Berth entry page: what Berth is, where to get it, pairing in three steps; once paired, open it without signing in.
  Berth 入口页：介绍、下载地址、三步配对；配对后一键免登录打开。

### Easier to find your way · 更好找
- Long pages get a table of contents (right side on wide screens, chips under the top bar elsewhere).
  长页面自动生成「本页目录」：宽屏在右侧，窄屏在顶部。
- The setup wizard asks where you open the panel from and ends with the next useful things.
  设置向导会问你从哪里打开面板，最后列出接下来最该做的事。

### Proxy usage · 代理用量
- Per node and per user, for any period: the last hours, today, yesterday, 7 / 30 days, this or last month, since creation, or chosen dates — with the busiest hour or day and who used it.
  每个节点、每个用户都能按任意时段看用量：最近几小时、今天、昨天、7 / 30 天、本月、上月、建立以来或自选日期，还有最忙的时段和谁用的。
