**Wharf 码头 0.18.1 — sharper alerts and device status · 告警与设备状态细化**

### Install / upgrade · 安装与升级
Panels on 0.17 / 0.18 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 / 0.18 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.18.1-1_<arch>.ipk
```

### Alerts · 告警推送
- **Device left / came back, separately.** Two switches, for the devices you pick or for all of them, driven by the same presence tracking as the dashboard (a device unseen for 10 minutes has left; a dozing phone does not count). Several devices in the same minute become one message, and the return says how long it was away. A 0.18 "offline watch" list carries over.
  **设备离开 / 回来分开设置**：可选设备或全部设备，和概览的进出记录同一套判断（10 分钟没出现才算离开，手机息屏不误报）；同一分钟的多台设备合并成一条，回来时附离开时长；0.18 的「离线提醒设备」自动沿用。
- **Every alert has its own switch.** DDNS failures, monitors and proxy-user alerts used to be always on.
  **每类告警都能单独开关**：DDNS 失败、定时监控、代理用户告警以前无法关闭。
- **Internet down vs. one line down.** "Internet down / back" is clearly the whole home; with several WAN lines, one line going down (and back) is reported on its own.
  **整个家断网和单条线路掉线分开**：多线路时其中一条掉线 / 恢复也会提醒。
- **Traffic spikes** per hour or per day, with per-device thresholds and devices left out (NAS, backups).
  **流量异常**：按小时或按天，可单设阈值、排除 NAS / 备份机。
- **New devices**: a phone that switched to a new private MAC is recognised by its name; randomised MACs can be ignored altogether.
  **新设备**：换了私有 MAC 的已知手机按名称认出，不再提醒；也可忽略所有随机 MAC。
- **Proxy early warnings**: 80 % of traffic used, expiring within 3 days, certificates not renewing.
  **代理提前提醒**：流量用到 80%、3 天内到期、证书没有续期。

### Devices and dashboard · 设备与概览
- The device list tells **online**, **not responding** (just went quiet) and **left** apart.
  设备列表区分「在线」「暂时无响应」「已离开」。
- Recent events filter by type (left / back, new devices, internet and lines, controls, security) and show up to 200; internet and line outages are now listed too.
  最近事件可按类型筛选、查看更多，并记录断网与线路事件。

### Controls · 设备管控
- Blocking a device says what it does: only the internet is cut, the NAS, printers and the router stay reachable. New option **also block the router** while blocked (DHCP and DNS stay open); it cannot be enabled for the device you are using.
  断网写清只断外网；新增「同时禁止访问路由器」（仍可获取 IP、解析域名），不能对正在使用的设备开启。
