**Wharf 码头 0.21.0 — Public address check, plugin import · 公网检测、插件导入**

### Install / upgrade · 安装与升级
Panels on 0.17 – 0.20 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 – 0.20 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.21.0-1_<arch>.ipk
```

### Is it really a public IP? · 到底是不是公网 IP
- The interfaces page now asks several outside services, through the WAN, which address they see, and compares it with the WAN's own address. Behind a modem it also looks one hop further out to tell whether the modem holds the public address or the ISP is doing carrier-grade NAT.
  「网络接口」页会从 WAN 口问几家外部服务看到的是哪个地址，和 WAN 口自己的地址对比；在光猫后面时再看光猫往外一跳，分辨公网 IP 在光猫上还是运营商大内网。
- Then it says what to do: with a real public IP that can change, set up DDNS in one click (existing records pointing home are listed); otherwise bridge mode / DMZ on the modem, asking the ISP for a public IP, IPv6 + DDNS, or a tunnel.
  接着给出下一步：真公网且地址会变，一键去设置 DDNS（已有指向家里的域名会列出来）；不是公网时建议光猫桥接 / DMZ、向运营商申请公网 IP、IPv6 + DDNS 或内网穿透。

### Import plugins into Wharf · 把插件导入 Wharf
- Plugins are split into *由 Wharf 管理* and *OpenWrt 原有插件*. Importing a plugin (or all at once) converts all its settings pages to Wharf's design in one go; afterwards pages open immediately with the router's current settings, no "converting" wait.
  插件分成「由 Wharf 管理」和「OpenWrt 原有插件」。导入（单个或全部）时一次性把所有设置页换成 Wharf 样式，之后打开即用，不再每次等待转换。
- Only the page structure is stored, never settings values or passwords. Plugins installed from the store are imported automatically; after a plugin upgrade Wharf asks to re-import.
  只保存页面结构，不保存任何设置值或密码。从插件商店安装的插件会自动导入；插件升级后会提示重新导入。
- Fixed: an open plugin page was re-converted every 20 seconds.
  修复：打开的插件页面每 20 秒会重新转换一次。
