**Wharf 码头 0.19.0 — Berth integration · 与 Berth 泊位联动**

### Install / upgrade · 安装与升级
Panels on 0.17 / 0.18 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 / 0.18 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.19.0-1_<arch>.ipk
```

### Pair with Berth · 与 Berth 配对
Berth is the server panel of the same series: Wharf runs the router, Berth runs the servers behind it. Nothing changes until you pair.
Berth 是同一系列的服务器管理面板：Wharf 管路由器，Berth 管它后面的服务器。不配对就什么都不变。
- Berth sends the super admin to Wharf to agree: which permissions, how long, and which devices are Berth hosts. Both sides then hold a token for the other; every call is signed, can't be replayed and is pinned to the certificate fingerprint checked at pairing. Everything Berth does is audited as 「Berth（name）」.
  由 Berth 发起，超级管理员在 Wharf 上确认权限、有效期和哪些设备是 Berth 主机。之后两边各持对方的令牌，每次调用都签名、防重放，并校验配对时核对过的证书指纹；Berth 做的所有改动都以「Berth（名称）」记入审计。
- *Settings → Berth 泊位*: status, narrow permissions, map Berth users to Wharf accounts, rotate tokens, unpair (keep or delete Berth's mappings). Protocol for implementers: `docs/BERTH.md`.
  「系统设置 → Berth 泊位」：查看状态、收窄权限、Berth 用户对应 Wharf 账号、轮换令牌、解除配对（可保留或删除 Berth 的映射）。对接协议见 `docs/BERTH.md`。

### What Berth can do · 配对后能做什么
- **Port mappings** for its own sites, only to its hosts, with a preview and conflict check first; they carry a Berth badge that opens the site in Berth. Admins see them read-only; a super admin can still change them and Berth is told.
  **端口映射**：只能指向 Berth 主机，先预览、查冲突；带 Berth 徽标，点开跳到 Berth。普通管理员只读，超级管理员仍可修改，Berth 会收到通知。
- **443 by name**: Berth registers its domains (`*.zone` too) with the SNI front, passed through untouched; proxy nodes and the panel's names keep priority.
  **443 按域名分流**：Berth 登记自己的域名（支持 `*.zone`），原样转给 Berth 主机；代理节点和面板域名优先。
- **DDNS** kept by one side per name; Berth can ask Wharf to keep a new name with the account it already has for that zone; names both update are flagged for you to choose.
  **DDNS** 每个域名由一方维护；Berth 可以请 Wharf 用同一区域已有的账号维护新域名；两边都在更新的会提示你选。
- **External bans**: a new section under 面板访问控制, dropping an address at the WAN for the router and its forwards (the LAN is unaffected). Bans from Berth show where they came from; your own can be synced to Berth one by one. A 封禁 button sits in a forward's connection list. Private addresses, the router's own IP, people signed in to the panel and anything wider than /16 are refused; IPv4 only for now.
  **外部封禁**：「面板访问控制」新增一节，在 WAN 口丢弃某地址发往路由器和端口转发的流量（局域网不受影响）。来自 Berth 的标明来源，自己加的可以单条同步到 Berth；端口转发的连接列表里有「封禁」按钮。内网地址、路由器自己的地址、正在用面板的人、大于 /16 的网段不能封；暂只支持 IPv4。
- **Alerts** from one side only (choose Wharf or Berth), repeats within 10 minutes sent once; **sign in without a password** in both directions; Berth hosts get a tag and a Berth tab on the device page; the audit page filters to Berth's actions.
  **告警**只由一方发送（可选 Wharf 或 Berth），10 分钟内重复的只发一次；两边**互相免登录跳转**；设备页给 Berth 主机加标签和 Berth 标签页；审计可只看 Berth 的操作。
