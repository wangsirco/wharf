**Wharf 码头 0.23.0 — Remote access in one place, menu groups, undo · 外网访问、菜单分组、撤销**

### Install / upgrade · 安装与升级
Panels on 0.17 – 0.22 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 – 0.22 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.23.0-1_<arch>.ipk
```

### Remote access · 外网访问
- One page for opening the panel from outside: how it is reachable now, the three ways (Cloudflare Tunnel, orange cloud, direct) with the one recommended for your line, the panel's names, and who may come in.
  一个页面说清「从外面打开面板」：现在的情况、三种方式（隧道 / 橙色云 / 直连）以及按你家线路推荐哪种、面板域名、谁能进来。

### Menu · 菜单
- Grouped as home network, control, tools, router, management and links. "DNS 拦截" is now "NextDNS 统计" and links to DHCP / DNS (and back).
  菜单分成家里网络、控制、工具、路由器、管理、联动；「DNS 拦截」改名「NextDNS 统计」，和「DHCP 与 DNS」互相跳转。

### Undo · 撤销
- After saving a change that can be restored, a toast offers to take it back (only by you, within two minutes).
  保存可还原的改动后会出现「撤销」，两分钟内本人可以一键恢复。
