**Wharf 码头 0.18.3 — Cloudflare account, public panel access, clearer alerts · Cloudflare 账户、面板公网访问、告警排版**

### Install / upgrade · 安装与升级
Panels on 0.17 / 0.18 show this update in the top bar (*Settings → Version & updates*). New installs:
0.17 / 0.18 的面板会在顶栏提示更新（「系统设置 → 版本与更新」）。全新安装：
```sh
opkg install /tmp/luci-app-wharf_0.18.3-1_<arch>.ipk
```

### Cloudflare account and DDNS · Cloudflare 账户与 DDNS
- Connect a Cloudflare account once: a link opens Cloudflare's token page with the permissions already chosen (read zones, edit DNS); paste the token back. Then pick a domain from the list, add a subdomain, or take over an existing record.
  连接一次 Cloudflare 账户：链接会打开权限已选好的创建令牌页面，粘贴回来即可；之后从列表选域名、新建子域名或接管已有记录。
- Plans for when to update — recommended, real-time, relaxed, timer only — and custom check intervals plus a forced refresh as a fallback (up to weekly).
  更新方案：推荐 / 实时 / 省事 / 只定时，也可以自定义检查间隔和兜底强制更新（最长每周）。

### Open the panel from outside · 从外网打开面板
- Public names for the panel (several allowed), one Let's Encrypt certificate for all of them, and a one-click DDNS record per name.
  面板可以有多个公网域名，一张 Let's Encrypt 证书覆盖全部，每个域名可一键用 DDNS 维护。
- Two ways in, either or both: **through 443** — the proxy extension's SNI front hands the panel's names to it, next to your website (1Panel) and proxy nodes, and passes on the visitor's real address so access control still applies; or **the panel's own port**.
  两种入口可同时开：**经 443**（代理扩展的分流器按域名交给面板，与网站和代理节点共存，访客真实 IP 照常受访问控制约束），或**面板自己的端口**。

### Alerts · 告警
- Each alert starts with an icon for its kind; every device gets its own block with its name in bold and labelled lines for type, address and times.
  每条告警以类型图标开头，每台设备一段，设备名加粗，类型、地址、时间分行标注。
- Devices that leave or come back within a few minutes of each other arrive as one message.
  几分钟内先后离开或回来的设备合并成一条消息。

### Fix · 修复
- The sidebar scrolls on its own when the window is short.
  窗口较矮时侧边栏可以单独滚动。
